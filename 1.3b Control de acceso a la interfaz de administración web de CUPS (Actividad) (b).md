# Control de acceso a la interfaz de administración web de CUPS (b)

Por defecto, sólo se puede acceder a la administración web de CUPS desde la máquina local y por parte de usuarios con derecho de administración. El objetivo de esta actividad es conocer las posibilidades de cambiar los permisos de acceso a CUPS tanto de máquinas remotas como usuarios. Para realizar esta tarea se piden las siguientes actividades:


**- Permitir que se pueda acceder a la interfaz web desde cualquier ordenador de la red.**

Para permitir que cualquier ordenador pueda acceder a la interfaz web, tendremos que editar el archivo de configuración de CUPS, mediante
el siguiente comando **(sudo nano /etc/cups/cupsd.conf)**, luego tendremos que buscar y modificar las secciones de **<Location />** y **<Location /admin>**, poniendo **(Allow all)** 
para que puedan tener acceso desde cualquier IP, por úiltimo tendremos que reiniciar el servicio cups para que se apliquen los cambios con el siguiente comando
**(sudo systemctl restart cups)**.
