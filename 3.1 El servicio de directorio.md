# Actividad 1: Esquemas LDAP estándar
### Objetivo

El objetivo de esta actividad es conocer los esquemas estándar LDAP y poder analizar los atributos obligatorios de una entrada con el tipo de clase objeto **inetOrgPerson**, 
así como proporcionar ejemplos de valores incorrectos para esos atributos.

### Análisis de la clase (inetOrgPerson)

Según lo que he visto en la documentación oficial del IETF **(RFC 2798, actualizada por las RFC 3698, RFC 4519 y RFC 452)**, 
y el resumen navegable disponible en Zytrax, obtenemos esta información:

- La clase de objeto inetOrgPerson no define los atributos obligatorios propios.

- **inetOrgPerson** no hereda atributos obligatorios de **organizationalPerson**.

- La clase organizationalPerson hereda de person los atributos obligatorios:

      - cn (**Common Name**)

      - sn (**Surname**)

La clase person hereda de top el atributo obligatorio:

- objectClass
