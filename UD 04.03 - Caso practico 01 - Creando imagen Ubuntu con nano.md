# UD 04.03 - Caso practico 01 - Creando imagen Ubuntu con nano

## 1. INTRODUCCIÓN
En este caso práctico vamos a crear y probar una imagen basada en “ubuntu” que simplemente
incluirá el editor de texto de consola “nano”.

2. PREPARANDO EL DOCKERFILE Y CREANDO LA IMAGEN
Crearemos el siguiente “Dockerfile”:

<img width="363" height="236" alt="image" src="https://github.com/user-attachments/assets/c0a46f13-fa53-4ef2-beb8-a0437b1d8893" />

Y pondremos en el fichero la información que nos ha proporcionado el ejercicio

<img width="579" height="119" alt="image" src="https://github.com/user-attachments/assets/e12ee530-abf1-4077-8d03-8d2509dde12e" />


El funcionamiento del propio “Dockerfile” está definido por sus propios comentarios. Una vez
preparado, crearemos la imagen con:
**(docker build -t ubuntunano ./)**

<img width="556" height="409" alt="image" src="https://github.com/user-attachments/assets/c6f2ae5c-66bc-49b1-bdaf-08a910243a16" />


<img width="792" height="454" alt="image" src="https://github.com/user-attachments/assets/777c507d-e1bd-4fe5-be7d-7624ed9b6b7a" />


Con esa línea indicamos que creamos la imagen “ubuntunano” basándose en el fichero
“Dockerfile” del directorio actual.

<img width="551" height="162" alt="image" src="https://github.com/user-attachments/assets/701a447f-5a52-45ed-a778-075a56bef450" />

## 3. PROBANDO LA IMAGEN
Con el siguiente comando, podremos crear un contenedor con esta imagen, acceder a una shell
dentro del contenedor y comprobar que el programa “nano” está instalado, ejecutando el editor
con “**nano prueba.txt**” o similar.

**(docker run -it ubuntunano)**
