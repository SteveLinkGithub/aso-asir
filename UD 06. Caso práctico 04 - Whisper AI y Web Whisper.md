<h1>UD 06. Caso práctico
04 - Whisper AI y Web
Whisper</h1>

<p>Whisper AI es un software que permite transcribir audio a Texto. Este software fue creado por
OpenAI (empresa creadora de ChatGPT) y liberado junto con varios modelos de procesamiento de
lenguaje muy precisos. Actualmente, es una de las mejores soluciones “self-hosted” para convertir
audio a texto.<br>
Whisper Web es una web, que proporciona una interfaz gráfica web para mandar audios a
transcribir a Whisper AI. Su repositorio es https://codeberg.org/pluja/web-whisper<br>
En este caso práctico vamos a poner en marcha una versión Dockerizada extraido de su repositorio
siguiendo las instrucciones de https://codeberg.org/pluja/web-whisper/wiki/Self-Hosting
</p>

<p>1. Clonaremos  el repositorio con el comando:</p>

```
git clone https://github.com/pluja/whishper.git

```
***Yo descargue esta porque el de la práctica me pedía un contraseña y usuario.***

<p>2. Tras ello, copiaremos y renombraremos el fichero “.env” de forma similar a</p>

```
cp example.env .env

```
