# Control de acceso a la interfaz de administración web de CUPS (b)

Por defecto, sólo se puede acceder a la administración web de CUPS desde la máquina local y por parte de usuarios con derecho de administración. El objetivo de esta actividad es conocer las posibilidades de cambiar los permisos de acceso a CUPS tanto de máquinas remotas como usuarios. Para realizar esta tarea se piden las siguientes actividades:


**- Permitir que se pueda acceder a la interfaz web desde cualquier ordenador de la red.**

Para permitir que cualquier ordenador pueda acceder a la interfaz web, tendremos que editar el archivo de configuración de CUPS, mediante
el siguiente comando **(sudo nano /etc/cups/cupsd.conf)**, luego tendremos que buscar y modificar las secciones de **<Location />** y **<Location /admin>**, poniendo **(Allow all)** 
para que puedan tener acceso desde cualquier IP, por úiltimo tendremos que reiniciar el servicio cups para que se apliquen los cambios con el siguiente comando
**(sudo systemctl restart cups)**.

**- Habilitar la interfaz web sólo en modo local o desde una dirección IP concreta.**

Para habilitar la interfaz web solo en modo local o desde una IP concreta, tendremos que limitar el acceso a la IP del cliente (**192.168.56.11**),
así que solamente esa IP podría acceder. Para tener acceso local tendríamos que poner **(Allow from 127.0.0.1**).

**- Permitir acceder a toda la interfaz de administración al usuario pepet, al grupo de profesores sólo para la administración de trabajos de impresión ya cualquier usuario correctamente identificado para gestionar las impresoras.**

El punto 3 consiste en controlar quién puede y quién acceder a cada parte de la administración de CUPS: para empezar el usuario pepet es el único que tendría acceso completo al (**/admin**), es por eso que el grupo profesores solo podría gestionar los trabajos de impresión (**/jobs**), y el resto de usuarios autenticados podría enviar los trabajos y gestionar la impresoras (**/printers**). Para ello deberemos de configurar el archivo de configuración de (**/etc/cups/cupsd.conf**) usando los bloques **<Location>**, **AuthType Default** y las directivas **Require user**, debido a ello **Require user @grupo** o **Require valid-user**, necesitan que se asignen los permisos específicos según el usuario o el grupo, y que solo los usuarios que estén autorizados para hacer esa acción.
